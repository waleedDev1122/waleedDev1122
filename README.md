## 🧠 How I work with AI

> **AI gets you to 80%. Review is the job.**

I use Claude Code every day to explore unfamiliar code, plan changes, write and refactor, debug, and prepare pull requests. Every AI-generated change gets the same review bar as any other code, and I spend as much time reviewing as I do writing.
